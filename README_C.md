

# Περιγραφή Εργασίας: Υλοποίηση ενός Στοιβαγμένου Διπλής Κατεύθυνσης RNN

 Σε αυτό το μέρος συγκρίνουμε τα αποτελέσματα των αλγορίθμων του Μέρους Α' και Β' με ένα Στοιβαγμένο Διπλής Κατεύθυνσης RNN,που υλοποιήθηκε σε PyTorch.
 Το μοντέλο χρησιμοποιεί LSTM/GRU, Global Max Pooling και προκαθορισμένα embeddings Word2Vec, προκειμένου να βελτιώσει την απόδοση στην κατηγοριοποίηση κειμένου από το IMDB Large Movie Review Dataset.


 ## Απαιτήσεις

 Πριν την εκτέλεση του προγράμματος θα πρέπει να είναι κατεβασμένες σχετικές βιβλιοθήκες .Για την εγκατάστασή τους γράφουμε 
 ->pip install numpy pandas scikit-learn matplotlib tqdm torch torchvision torchaudio gensim

 ## Τρόπος μεταγλώτισσης και εκτέλεσης προγράμματος

Για τη μεταγλώτισση και εκτέλεση του προγράμματος , επειδή τον κώδικα τον υλοποιήσαμε σε python notebooks σε vs code , θα πρέπει για το συγκεκριμένο αρχείο notebook (Rnn.C.ipynb) να πατήσετε σε κάθε cell το κουμπί run code για να τρέξει το αντίστοιχο cell

 ## Dataset

Για το project χρησιμοποιήσαμε το IMDB Large Movie Review Dataset και το σχετικό link ,δίνεται στην περιγραφή της εργασίας

## Outputs

Στο output περιλαμβάνονται -> 1) Καμπύλες απώλειας (Loss) για τα δεδομένα εκπαίδευσης και ανάπτυξης και 2) πίνακες με αποτελέσματα ακρίβειας (precision), ανάκλησης (recall), F1 για κάθε μία από τις δύο κατηγορίες και μέσους όρους (microκαι macro-averaged), στα δεδομένα αξιολόγησης (test data), όταν χρησιμοποιούνται όλα τα δεδομένα εκπαίδευσης.Λεπτομέρειες παρατίθενται στο σχετικό report
